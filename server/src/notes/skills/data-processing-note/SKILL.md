---
name: data-processing-note
description: Draft a note on data transformations, field mappings, validation, and gaps affecting downstream use.
---

Use the supplied transformation evidence and the user's focus to write a reviewable processing note.

1. Identify the input and output, the row or entity grain, and the fields affected when these details are present.
2. Describe relevant mapping, normalization, filtering, joining, deduplication, or missing-value rules with their exact field names and conditions.
3. Separate reported checks and counts from proposed checks. State visible exceptions, unresolved mappings, and the possible effect on downstream work.
4. If the material shows only a preview or summary, describe the scope of the evidence and name a concrete remaining validation check when useful.

Use compact sections or the user's requested structure. Preserve important identifiers and any distinct meanings of empty, unknown, and zero.
