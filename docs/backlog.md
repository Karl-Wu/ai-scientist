## 笔记与笔记页

「笔记」是项目入口，「笔记页」是可打开、修订和引用的内容。原始依据来自已有任务执行记录、结果卡片或文件。笔记存储与浏览在现有后端内独立组织，项目为归属范围，任务用于筛选和溯源。

### 第一版待办

- [ ] **笔记页存储与接口。** 复用项目范围校验和本地文件读写逻辑。新增项目级读写接口，保存标题、正文、笔记类型、来源引用、整理专家、审阅状态和修订版本。一个笔记页可以引用多个任务。
- [ ] **笔记类型与浏览。** 复用现有列表、搜索、Markdown 和文件预览。用通用卡片浏览，详情按类型展示和校验字段。先用科研「假设、观察、决策」与数据加工「映射规则、质量检查、处理决策」验证两套类型可共存。支持按类型、来源任务和整理专家筛选。
- [ ] **审阅与查看出处。** 打开笔记页时可查看、审阅和修订。复用现有任务和文件预览入口，定位有锚点的消息、工具结果和文件。只能定位到任务时，展示已引用的片段并打开原任务。重新写入保留人工修订。
- [ ] **移除实时 `notebook` 写入。** 从主 Agent 和专家 Agent 的工具、提示词及实时日志提示中移除该流程。任务执行记录和科学结果卡片继续提供材料。

第一版验收使用两类样例笔记页，核对同一项目内写入、重开后读取、类型筛选、不同字段显示、人工修订保留和来源跳转。另运行一轮普通任务，核对任务仍正常展示工具调用和结果。旧日志兼容留待后续，证据包单独讨论。

### 待讨论：接入后台整理专家

- **触发与输入范围。** 当前讨论起点是用户从一个已完成的任务发起「整理笔记」，读取相关对话、工具结果及已有结果卡片。跨任务选材和自动触发另行讨论。
- **整理规则与写入。** 专家定义关注点、允许生成的笔记类型和字段。候选笔记页附出处，经服务端校验后写入，进入待审阅。材料不足时可以返回零页。整理只读已有材料，新实验和新计算另行授权。
- **运行机制。** 后台任务的进度、取消、重启恢复、费用和去重范围待定。先验证单任务能否提取出用户愿意保留的笔记页，再决定接入范围。实验回顾和证据审阅作为后续角色另议。
